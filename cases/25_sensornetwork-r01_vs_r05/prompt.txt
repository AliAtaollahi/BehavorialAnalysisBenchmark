A weak timed bisimulation expresses that two states are not distinguishable by the $\xRightarrow{a}$ $\toverto{t}$ relations.
\begin{definition}[Weak Timed Bisimulation]
\label{def:twt-equivalence}
Let $\mathcal{T}=(S,\Act_\tau,\rightarrow,s_0)$ be a timed transition system. A binary relation $\mathcal{R}\subseteq S\times S$ is a \emph{weak timed simulation} if $s\,\mathcal{R}\,u$ implies:
\begin{enumerate}
  \item for every $a\in\Act$, if $s\xRightarrow{a}s'$, then there is a state $u'$ such that $u\xRightarrow{a}u'$ and $s'\,\mathcal{R}\,u'$;
  \item for every $t\in\int$, if $s\toverto{t}s'$, then there is a state $u'$ such that $u\toverto{t}u'$ and $s'\,\mathcal{R}\,u'$.
\end{enumerate}
A relation $\mathcal{R}$ is a \emph{weak timed bisimulation} if both $\mathcal{R}$ and $\mathcal{R}^{-1}$ are weak timed simulations. Two states $s$ and $u$ are \emph{weakly timed bisimilar}, written $s\simeq_{wtb}u$, if $s\,\mathcal{R}\,u$ for some weak timed bisimulation $\mathcal{R}$.
\end{definition}
